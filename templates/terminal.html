Training Terminal

Practice lab. This is a real in-browser Linux-style terminal: standard commands genuinely execute inside your own browser (xterm.js shell, Pyodide Python, in-browser virtual filesystem). Nothing you type is sent to the Dark Matrix server for execution. Your server never runs it. Type help to see what works.

Real commands run in your browser: ls, cd, pwd, cat, echo, grep, mkdir, touch, rm, cp, mv, wc, head, tail, sort, uniq, python3, python. Files live in an in-browser virtual filesystem that resets on refresh. Network tools like nmap/dig/ping are not included, the browser cannot do raw scanning. Use the AI assist panel for the right command or an error explanation.

Practice tasks

  1. Run ls, then cd practice and cat scan-notes.txt.
  2. Try echo hello, grep scan practice/scan-notes.txt, mkdir notes, touch notes/todo.txt, rm notes/todo.txt.
  3. Run real Python: python3 -c "print(2 + 2)" or type python3 for the interactive prompt, then print("hello from python").
  4. Run help for the full command list, then ask the AI panel for the right command if you get stuck.

What this is not

Not a real Kali install and not a scanner. Everything executes on your own device in a sandboxed virtual filesystem, so it cannot touch the Dark Matrix server, your real files, or the network. Real scanning and OSINT belong on dedicated labs with legal permission.
