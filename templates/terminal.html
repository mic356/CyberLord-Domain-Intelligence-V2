Commands allowed: help, nmap lab.local, dig, whois, ping, ls, cd, cat, pwd, echo, clear, theharvester -d domain -b google. Everything outside that list is rejected. Outputs are simulated for learning.

Practice tasks

  1. Run nmap lab.local and note the open ports.
  2. Run dig lab.local and compare the A record.
  3. Run theharvester -d example.com -b google and explain why this is simulated people-data style output.
  4. Use ls, cd practice, and cat scan-notes.txt.

What this is not

Not a real Kali install, not a real scanner, not an attack tool. Real scanning and OSINT belong on dedicated labs with legal permission. Here, every result is fictional and fixed in advance.
